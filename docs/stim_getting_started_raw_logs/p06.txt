## Interpretation

**Low noise ($p = 0.03$):** The distance-9 repetition code has minimum distance $d = 9$, so it can correct $t = \lfloor 9/2 \rfloor = 4$ errors. With $p_{\text{data}} = 0.03 \ll p_{\text{th}}$, the code is operating below threshold and MWPM successfully suppresses most error patterns. The ~3.4% logical error rate over 100 rounds reflects the accumulated probability that uncorrectable chains span the code.

**High noise ($p = 0.13$):** At $p_{\text{data}} = 0.13$, the code is operating well above threshold. Weight-$\lceil d/2 \rceil = 5$ error chains become likely in every round, and MWPM cannot reliably match them correctly. The logical error rate of ~49% is near the 50% random-guess limit — the code has essentially ceased to provide protection. This is consistent with the known phenomenology: for $p > p_{\text{th}}$, logical error rate *increases* with code size and rounds [^4].

**The threshold** for the bit-flip repetition code (under independent bit-flip + measurement noise) is well-known to be around $p_{\text{th}} \approx 10\%$ (the intersection of the logical error-rate vs. $p$ curves for different distances). Both $p = 0.03$ (below) and $p = 0.13$ (above) are consistent with this picture [^1][^5].

**MWPM** is the natural decoder here: each bit-flip error flips at most two adjacent parity checks, making the syndrome graph perfectly graphlike and MWPM exact (up to degeneracy) [^1].
