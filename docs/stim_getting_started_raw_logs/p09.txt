### 3. Why Is the Surface Code Threshold Lower?

The key reason is the **dimensionality and completeness of error correction**:

#### a) The repetition code only corrects one error type
The repetition code protects against only **bit-flip ($X$) errors** — it has no $Z$-type stabilizers. Its syndrome graph is a simple 1D chain, and a minimum-weight matching on that chain succeeds as long as fewer than $\lfloor d/2 \rfloor$ consecutive errors occur. For independent identically distributed noise of rate $p$, the threshold is $p_{\mathrm{th}} \approx 50\%$ in the ideal (noiseless syndrome) case, or $\sim 10\%$ under phenomenological noise.[^9]

#### b) The surface code must correct both $X$ and $Z$ errors simultaneously
The rotated surface code is a **CSS code** that must suppress both $X$-type and $Z$-type errors, each detected by separate sets of stabilizers.[^1] Under **circuit-level depolarizing noise**,[^2] errors are also introduced on ancilla qubits and during CNOT/CZ gates via the two-qubit channel:

$$\mathcal{E}_2(\rho) = (1-p)\rho + \frac{p}{15}\sum_{P \in \{I,X,Y,Z\}^{\otimes 2} \setminus \{II\}} P\rho P^\dagger$$

This injects *correlated* $X$ and $Z$ errors into the syndrome extraction circuit itself, including **measurement errors**. Each of these failure channels contributes independently to the logical error rate, making the effective noise significantly harder to decode.

#### c) Circuit-level noise is strictly harder than code-capacity noise
Under the **circuit-level model** (which our simulation uses), stabilizer measurement circuits introduce hook errors — single physical faults that propagate to produce weight-2 data errors in unfavorable positions — and measurement errors that persist across rounds. This raises the effective error load on the decoder substantially, depressing the threshold from the $\sim 10.9\%$ statistical-mechanics upper bound[^9] down to $\sim 1\%$ in practice.[^5][^7]

In contrast, the repetition code's 1D syndrome graph is much simpler: a single faulty CNOT can only affect one syndrome bit at a time, and the decoder can still succeed with a much higher noise floor.

#### d) Summary table

| Code | Corrects | Noise model | $p_{\mathrm{th}}$ (approx.) |
|---|---|---|---|
| Repetition code | $X$ errors only | Circuit-level | $\gtrsim 1.2\%$ (seen here) / $\sim 10\%$ at code-capacity |
| Rotated surface code | $X$ and $Z$ errors | Circuit-level depolarizing | $\sim 1\%$ |

The surface code's $\sim 1\%$ threshold is *lower* than the repetition code's, but the surface code is encoding a **full qubit** — protecting against *all* Pauli errors — at the cost of requiring a more noise-sensitive, higher-dimensional syndrome graph that is vulnerable to circuit-level error propagation.[^1][^2][^6]
